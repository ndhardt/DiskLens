# DiskLens

macOS向けのディスク使用量アナライザーです。容量を圧迫しているファイルを探し、Quick Lookやゴミ箱への移動まで行えます。

![DiskLens](docs/screenshot.jpg)

[最新版をダウンロード](https://github.com/ndhardt/DiskLens/releases/latest)

## 使い方

1. 調べるドライブまたはフォルダを選び、スキャンする
2. 目的に合う表示へ切り替える
3. 検索や並べ替えで対象を絞る
4. `Space` で内容を確認し、不要なら `⌘⌫` でゴミ箱へ移動する

| 表示 | 用途 |
|---|---|
| Tree | フォルダ階層ごとの使用量を見る |
| 容量ランキング | 容量の大きい項目を順に探す |
| ファイル種別 | 拡張子・カテゴリごとに集計する |
| クリーンアップ | キャッシュや古い大容量ファイルを確認する |

検索欄では、単語をスペースで区切るとAND検索になります。例:

```text
*.mov
size:>5GB
unused:>6m
kind:video path:Downloads
```

クリーンアップで自動選択されるのは再生成できる項目だけです。削除は直接消去せず、macOSのゴミ箱へ移動します。

## ショートカット

| キー | 操作 |
|---|---|
| `⌘F` | 検索 |
| `⌘R` | 再スキャン |
| `⌘1` | Tree |
| `⌘2` | 容量ランキング |
| `⌘3` | ファイル種別 |
| `⌘4` | クリーンアップ |
| `↑` / `↓` | 項目を移動 |
| `Shift` + `↑` / `↓` | 範囲選択 |
| `Space` | Quick Look |
| `⌘O` | 開く |
| `⌘⌥C` | パスをコピー |
| `⌘⌫` | ゴミ箱に入れる |
| `Esc` | 選択解除、検索やポップアップを閉じる |

右クリックからも、開く・Quick Look・Finderに表示・パスをコピー・Treemapで表示・ゴミ箱に入れる、を実行できます。
